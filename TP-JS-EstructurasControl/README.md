# TP-JS-EstructurasControl-[Apellido]

Trabajo Práctico N°1: Estructuras Condicionales y Entrada de Datos en JavaScript.

## Estructura

- `index.html`: página principal para seleccionar cada ejercicio.
- `js/ejercicio01.js` a `js/ejercicio10.js`: resolución de los ejercicios.

## Cómo ejecutar

1. Abrir la carpeta en Visual Studio Code.
2. Abrir `index.html` en el navegador.
3. Seleccionar el ejercicio correspondiente.
4. Los ejercicios que utilizan `console.log()` se pueden consultar con F12 -> Consola.

Reemplazar `[Apellido]` por el apellido del alumno al crear el repositorio de GitHub.
